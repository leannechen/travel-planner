Kind dropdown

  • The trigger takes the kind’s tint, edge color and icon, so a panel reads as its kind at a glance. Icon and name carry the meaning; color is the second cue.
  • One row at 400 px. The four chips used to wrap to two rows.
  • Arrow keys move, Enter picks, Esc closes, the first letter jumps to a kind.
  • The choice waits for Save. Switching shows the note under the dropdown (#09).

Footer

  • Left: moves or removes the Event (the ⋯ menu). Right: Cancel discards typed changes, Save saves and closes. Save is the only filled button.
  • The footer stays at the bottom while the body scrolls. Enter saves; Esc asks about unsaved changes (PRD §3.2).
  • Save is not disabled. A new Event without a title answers “a title is needed”.
