# v1 collaboration is lightweight: invited Editors, last write wins

Trips can be shared with invited Editors (by email, login required) in v1. Changes propagate to other collaborators promptly, and conflicts resolve per Event with the last write winning; there are no live cursors and no merging of simultaneous edits to the same field. We chose this over full real-time co-editing because it covers the core need of travel companions planning together at a fraction of the technical risk. Offline read-only support is moved to a later phase to make room for it.

## Considered Options

- **Full real-time co-editing** (presence, simultaneous edits, automatic merge): much higher cost for little extra value in this domain.
- **Link-sharing read-only only**: simplest, but does not meet the need for shared planning.
