Notes for review

Left sidebar, collapsible like Backlog. It sits left of Backlog on desktop; on phone it is a full screen reached from the Trip title.
“Shared with me” lists Trips where I am an Editor. Viewers with a link are not listed.
Menu follows roles: Editors do not get Delete, Share or Rename-owner actions (Trip settings is read-only for them, to confirm).
Delete needs its own confirmation, with a title-typing step. That step is a proposal.
New Trip offers two choices: “Blank Trip” (title, start date, default travel mode) and “Generate with AI” (prompt field, example prompts, and the daily limit note). Each has a Back link to the chooser. While generating, see the loading state on the States board. When the daily limit is reached, the message replaces Generate (errors board).
Blank Trip asks the default travel mode at creation, as the PRD says. Import backup creates a new Trip.
Search, folders, favourites and drag-to-reorder are not in the PRD, so not drawn.
Where the sidebar sits relative to Backlog and Archive on narrow desktops is open.
