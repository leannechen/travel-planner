Behaviour

RemoveNo image for this Event. Hides the Google photo too.
Use place photoBack to the default. Needs a location.
Location changesThe default photo swaps to the new place. An uploaded image stays.
Location clearedNo place photo. Upload stays; otherwise state 4.
Upload removedGoes to “no image” (state 3), not back to the photo. Matches Remove.
