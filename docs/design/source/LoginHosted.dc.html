Entry points

Every entry point opens this Auth0 page directly, with no prompt dialog in between: the Landing “Log in” link · the guest “Log in to save your progress” button · Share, Export and New Trip · the session-expired banner · the invitation page “Log in” and “Sign up” buttons (Log in opens the log-in screen, Sign up opens the sign-up screen with screen_hint=signup; both prefill the invited email with login_hint).

Design notes

Every entry point opens this page directly, with no prompt dialog in between (see the box at the top of the board).
This page is hosted by Auth0 and only themed: logo, colors, Nunito for headings and Inter for text, our radii, button style and a background image with a veil. It has no language or theme switch of ours, so none are drawn. The address bar strip shows it is a different page.
Log in and sign up are two Auth0 screens linked by “Don’t have an account? Sign up” and “Already have an account? Log in”. Fields are only what Auth0 provides: email and password on both screens, and no name or confirm-password field. Show-password toggle, “Forgot password?” (log in only) and the terms line are Auth0 elements. Email and password only: Google login is a next-phase item, so there is no social button or “or” divider.
No tabs: Auth0 renders the form itself (page templates only wrap it, and its CSS class names change with every Auth0 build), so tabs would need Advanced Customizations (ACUL). The terms line sits outside the card, in the page template footer.
Error: Auth0 says “Wrong email or password.” and does not say which one was wrong. The text is Auth0’s default. The password rules line under Sign up is a placeholder; the real rules come from the Auth0 tenant.
No dark version: Auth0 documents no dark mode for the hosted page, and styling the form with custom CSS is unreliable. The page stays light whatever the app theme is.
Language: the app passes ui_locales=zh-TW when the interface is in Traditional Chinese (zh-TW must be enabled in the tenant). The second row shows that; the Chinese strings are placeholders, Auth0 supplies its own.
