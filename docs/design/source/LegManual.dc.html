Design notes · duration entered by hand

Why: Google gives no public-transit routes in Japan (ADR 0009), so a transit Leg there can only say “can’t calculate”. The user looks the route up in Google Maps and types the minutes.
The field appears for any Leg whose two Events both have a place and whose duration Google could not calculate, in any travel mode. The app never decides by country. If an Event has no location there is no field (board 25, frame 4).
The “Open in Google Maps” link and the no-transit note sit above the field. Whole minutes from 1 to 1,440; Save stores the number. An invalid number shows an error under the field.
Once set, the Leg shows the duration with a small pencil mark, and the popover shows the number with an (i) icon next to “Duration”; hovering or focusing it (tapping on phone) shows the tooltip “Entered by you”. No distance. The field is only shown while the duration is empty (frame 1) or while editing it. Editing (Edit, then Save or Cancel) is shown in board 25c.
The conflict warning uses the entered duration like a calculated one (frame 3).
Changing the travel mode or either Event’s location drops the entered duration and the Leg is calculated again. No extra UI for this.
Changing only an Event’s time keeps it and shows the toast (frame 4): non-blocking, once per save, no button other than dismiss.
Texts are proposed, in English first; Traditional Chinese versions are written at build time.
