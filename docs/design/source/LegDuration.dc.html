Design notes · editing a duration

The field is shown only while the duration is empty (board 25b, frame 1). Once there is a value, the popover shows “25 min” with an Edit button and an (i) icon next to “Duration”; its tooltip says “Entered by you” (board 25b, frame 2).
Edit shows the field with the current number. Save stores it; Cancel or Esc goes back without a change. A number outside 1 to 1,440 shows an error under the field and keeps the old value.
Clear duration is only in edit mode, so it is not hit by accident. It returns the Leg to “can’t calculate”.
Phone: the same, with 44 px targets.
Decided 2026-10-23: Edit button rather than clicking the number to edit with autosave on blur. A change stays deliberate, and the field behaves like the empty state.
