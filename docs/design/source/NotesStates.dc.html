Design notes

The Notes panel has three states: a new Note, the list of Notes, and one open Note. The same three states are drawn on desktop and phone, in light and dark.
Toolbar: “+” starts a new Note, the list button opens the list, “×” closes the panel (Esc does too). The button for the state you are already in is disabled: “+” while a new, empty Note is open, the list button while the list is shown.
The header is the drag handle on desktop; the panel keeps within the window. On phone the panel is a full-width bottom sheet with 44 px buttons.
A new Note is not saved until something is typed, so an empty Note never appears in the list. Notes autosave; an open Note shows “Saved” at the bottom.
List: pinned Notes first, then the rest by most recent edit. The row title is the first line of the Note. Clicking a row opens that Note.
Row buttons: the pin button is filled when the Note is pinned (tooltip “Unpin”) and outlined otherwise (tooltip “Pin”). The trash button deletes the Note and shows an Undo toast, as for Events.
Closing and reopening Notes returns to the Note that was open (kept for the browser session). Only the first open of a session starts a new Note.
The Write and Preview tabs of the Event Description editor are not part of this panel; the field shows the Markdown text as typed.
